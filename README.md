# Inteligência Artificial e Machine Learning

## Projetos Desenvolvidos

* **[Processamento de Linguagem Natural (Seq2Seq + Attention)](./nlp-traducao-lstm-attention/):** Treinamento de uma rede Recorrente LSTM bidirecional com Mecanismo de Atenção (TensorFlow/Keras) para tradução semântica de datas. Estudo focado no problema de *data bias* e na estabilização de épocas.
* **[Visão Computacional e Detecção de Objetos (YOLOv3)](./visao-computacional-yolo/):** Implementação e análise crítica do algoritmo *Single Shot Detector* YOLO para detecção multiclasses. Otimização matemática de *Bounding Boxes* utilizando filtros de Limiar de Confiança e *Intersection over Union (IoU)*.
* **[Aprendizado por Reforço (Deep Q-Learning)](./q-learning-agente-cobrinha/):** Construção integral de um Agente Virtual que aprende a jogar o jogo da Cobrinha de forma autônoma. O modelo mapeia estados ambientais e executa tomadas de decisão através de uma Rede Neural PyTorch alimentada pela Equação de Bellman.
* **[Otimização de Redes Neurais (Matrix Chain Multiplication)](./otimizacao-redes-neurais-pytorch/):** Um estudo de caso técnico unindo Programação Dinâmica a modelos de Deep Learning, comparando o custo teórico da multiplicação de matrizes ao *overhead* de grafos computacionais (PyTorch).

## Tecnologias Utilizadas
* **Linguagem:** Python
* **Frameworks de IA:** PyTorch, TensorFlow, Keras, OpenCV.
* **Conceitos:** Deep Q-Learning (DQN), Redes Neurais Convolucionais (CNNs), Long Short-Term Memory (LSTMs), Attention Mechanism.
